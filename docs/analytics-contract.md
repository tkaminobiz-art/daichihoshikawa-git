# 星川大地公式サイト GA4計測契約 v1

## 正式設定

- 対象: `https://www.daichi-star.com`
- GA4測定ID: `G-J6GN9VDFTP`
- WebストリームID: `15764835576`
- プロパティID: `553863848`
- タイムゾーン・通貨: `Asia/Tokyo` / `JPY`
- Google管理画面で確認済み: 拡張計測OFF
- 実装方式: 明示的な許可後だけGoogleタグを読み込む基本同意方式

## イベント契約

| 項目 | 内容 |
|---|---|
| イベント名 | `page_view` |
| 目的 | 許可した閲覧者が、どの公開ページを閲覧したかをサイト改善に用いる |
| 判断主体 | サイト運用者。実運用上の責任者氏名は未確認 |
| 発火条件 | 解析許可後の初回表示と、許可中のpathname変更 |
| 発火しない条件 | 未選択、拒否、撤回後、同じpathnameの重複、query/hashだけの変更 |
| 必須値 | `page_location`（origin＋pathname）、`page_path`、`page_title`、空の`page_referrer` |
| 任意値 | なし |
| 重複防止 | 同一クライアント実行中はpathname単位で1回 |
| 送信先 | Google Analytics 4 `G-J6GN9VDFTP` |

Googleタグが同意後に生成する標準の `session_start`、`first_visit`、`user_engagement` は許容する。サイト側が明示的に送るイベントは `page_view` のみとする。

## 同意状態

| 状態 | Googleタグ | 解析送信 | 保存 |
|---|---|---|---|
| 未選択 | 読み込まない | 送信しない | なし |
| 拒否 | 読み込まない | 送信しない | `denied` の選択値のみ |
| 許可 | 読み込む | `page_view` とGA標準自動イベントのみ | `granted` の選択値とGA Cookie |
| 撤回 | 測定ID単位で停止後、ページ再読み込み | 撤回後は送信しない | GA Cookieを削除し、`denied` の選択値のみ |

同意の保存先はlocalStorageの `daichi.analytics-consent.v1`。訪問者ID、時刻、入力値は保存しない。

## 送信禁止データ

- 氏名、メールアドレス、電話番号、住所、問い合わせ内容
- 制度ナビなどの検索欄・フォームの入力値
- URLのqueryとhash
- referrer
- User-ID、ユーザープロパティ、精密位置情報
- 独自クリック、フォーム、スクロール、検索イベント
- 広告向けユーザーデータ、広告パーソナライズ信号

`allow_google_signals` と `allow_ad_personalization_signals` は測定ストリーム単位でfalseにする。広告同意は常にdeniedとし、既存のGoogle Ads設定やイベントは追加・変更しない。

## 公開前後の検証条件

1. 未選択・拒否時にGoogleタグとGA通信が0であること。
2. 許可後にタグが1回だけ読み込まれ、サイト側の `page_view` が1回だけ送信されること。
3. query、hash、referrer、入力マーカーがGAリクエストに含まれないこと。
4. 撤回直後に測定ID単位の停止が有効になり、再読み込み後もタグ・通信が0であること。
5. `/`、`/support`、`/profile` と、メニュー・制度検索が従来どおり動作すること。
6. GA管理画面での受信確認はGoogle管理担当が別途実施すること。
